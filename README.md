
# Project Data Acquisition

## Deskripsi
Repository ini berisi tugas praktikum mata kuliah Akuisisi dan Manajemen Data tentang pemetaan Data Science Lifecycle.

## Tujuan
Memahami tahapan Data Science Lifecycle, aktivitas utama, contoh tools, dan risiko pada setiap tahap.

## Tahapan Lifecycle
1. Acquisition
2. Storage
3. Cleaning
4. Transformation
5. Analysis
6. Delivery

## Tools
- Acquisition: Python Requests, BeautifulSoup
- Storage: MySQL, PostgreSQL
- Cleaning: Pandas, OpenRefine
- Transformation: Pandas, Apache Spark
- Analysis: NumPy, Scikit-learn
- Delivery: Matplotlib, Power BI

## Struktur Repository
- README.md: Dokumentasi proyek
- main.py: Kode Python
- docs/lifecycle.csv: Tabel pemetaan Data Science Lifecycle

## Cara Menjalankan
Install Pandas:

pip install pandas

Jalankan program:

python main.py

## Mata Kuliah
Akuisisi dan Manajemen Data
